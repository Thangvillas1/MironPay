Design system

MironPay Obsidian

The visual system behind the MironPay mobile wallet. One typeface, one accent, flat bordered surfaces, and gold used as stroke and state rather than fill. Dark is the primary ground; light is a full parallel token set, not a tint.

Space Grotesk #c9a35f accent Dark + light parity Pill actions · 12–18px cards
01

Color

Every color is a CSS variable set on a theme class — .thm-dark or .thm-light. Components never name a hex. The two themes carry the same sixteen roles, so a screen built once renders in both without a single conditional.

Elevation is carried by borders, not shadows. The system has exactly two shadows: the raised QR tab button and the desktop preview bezel. Overlays darken instead — rgba(0,0,0,.5) for sheets and dialogs, a 94% wash of the ground for busy states.

06

Biometric pattern

One viewfinder component covers every authentication moment — app entry, and confirming a send, a swap, or a merchant payment. The bracket and glyph carry the state; the copy changes, the geometry never does.
{{ f.title }}
{{ f.sub }}
Rules
Viewfinder is always near-black #08080a, in both themes — it reads as a camera, not as chrome.
Scan resolves in 1300ms; success holds 550ms before acting.
A PIN fallback is always one tap away, and becomes the only path after three failures.
Authorizing an outgoing action requires it. Watching an incoming payment does not.

08

Do & don't

Do
Draw containers with 1px borders and let the ground stay flat.
Keep one filled gold action per screen, pinned to the bottom.
Set every figure tabular so numbers never reflow.
Reuse the same confirm dialog and biometric gate for all three transaction types.
Keep touch targets at 44px and above.
Don't
Don't add a second accent — gold is the only chromatic voice.
Don't fill cards, rows, or sheets with solid gold.
Don't introduce drop shadows for hierarchy; use a border or a ground shift.
Don't mix in a second typeface, and don't reach past weight 700.
Don't invent a hex — if a role is missing, add it to both themes.
